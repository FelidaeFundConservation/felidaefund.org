Concept

An interactive range map

The distribution map on every species page is a screenshot. It cannot be zoomed, cannot be read by a screen reader, goes soft on a retina screen and cannot be restyled. This is the same information drawn live in the browser.

Vector, so it is sharp at any size. Keyboard reachable. Styled with Felidae's own palette. One file serves all 40 species.

We can build this without asking anyone

The country shapes are public domain. Natural Earth, used by news organisations and governments, free for any purpose with no attribution required.

Which countries a species lives in is a fact, not a dataset. It is published in the assessment text and facts cannot be owned. We cite the source and move on.

So the only thing IUCN permission would ever buy is finer geometry — their irregular shapes that cut across borders instead of whole countries. That is a precision upgrade, not a prerequisite. If it is ever wanted, it is a letter. Nothing here waits on it.

The bands shown are placeholder. Which country sits in which was filled in to make the interaction legible and has not been checked against the assessment. Read the behaviour, not the data.

What it buys

  • It stops going blurry. Vector redraws at any size, on any screen, forever. The current maps are being shown above their own resolution.
  • It can be read aloud. Right now the map is an image with one long alt string. Here every country is a focusable element with its own status.
  • It looks like Felidae. The current maps carry Esri's default styling and a Leaflet watermark, because they are screenshots of somebody else's viewer.
  • It is one component, not forty files. Today each species carries its own JPEG. This is one file plus a short list per species.
  • It can carry the work. A resident country where Felidae runs a project could link straight to that project.

What it costs

  • Checking the range countries for 36 species against the assessments. A list, not a project.
  • Building the component once. It is one SVG and one short script, already done here.
  • Building it twice if it ships before the move rather than after.

The honest limit

Country-level is coarser than the screenshots it replaces. Cheetahs do not live in all of Namibia, and this shows the whole country. So it should be labelled range countries, not range — saying what it actually shows rather than implying a precision it does not have.

Whether that trade is worth it is the real question: a coarse map that is sharp, readable aloud, on-brand and ours, against a precise one that is blurry, silent to a screen reader and someone else's.
